1MCP là gì, khác Skill ở đâu

Tới giờ Agent chỉ làm việc với file trên máy: đọc, viết, sắp xếp. Muốn Agent vẽ ảnh, đọc mạng xã hội, xem lịch hẹn, Agent phải nối được sang phần mềm khác. MCP là cách nối đó.

1.1. Hình dung MCP như ổ cắm điện

Ổ cắm trong nhà có một chuẩn chung: quạt, nồi cơm, cục sạc, hãng nào cũng cắm vào là chạy, không ai phải đi dây riêng cho từng món. MCP là chuẩn ổ cắm cho Agent. Phần mềm nào làm "phích cắm" theo chuẩn MCP thì cắm được vào Antigravity, và cũng cắm được vào các phần mềm Agent khác dùng cùng chuẩn.

AgentNgười dùng điện: nhận câu lệnh của bạn, tự quyết lúc nào cần dùng công cụ nào.Trong khóa: Agent của Antigravity.
MCP serverThiết bị cắm vào ổ: một phần mềm nhỏ chạy trên máy bạn, hoặc chạy trên mạng.Hôm nay: chatgpt-image, chạy trên máy bạn, nối sang ChatGPT.
Công cụ (tool)Các nút bấm trên thiết bị. Mỗi MCP mang theo vài công cụ, Agent bấm đúng nút cho từng việc.Ví dụ: generate_image để vẽ ảnh, login_status để xem đã đăng nhập chưa.
Bạn: "Tạo ảnh ly cà phê cho tôi" │ ▼ Agent (Antigravity) tự chọn công cụ generate_image │ ▼ MCP chatgpt-image chạy trên máy bạn, giữ mã đăng nhập ChatGPT │ ▼ ChatGPT vẽ ảnh theo mô tả │ ▼ anh/thu/....png ảnh lưu thẳng vào dự án, bạn không phải tải tay

1.2. Skill là cách làm, MCP là công cụ

Hình dung một bếp ăn: Skill là công thức nấu ăn, ghi bước nào trước, nêm bao nhiêu. MCP là cái bếp, cái nồi. Có công thức mà không có bếp thì món ăn chỉ nằm trên giấy; có bếp mà không có công thức thì mỗi lần nấu ra một vị.

Câu hỏi nhanh: mỗi việc dưới đây cần Skill hay MCP?

C. Mỗi ảnh tạo xong phải ghi vào file danh sách ảnh kèm prompt đã dùng.
Đáp án: A và C là cách làm, viết thành Skill. B cần nối sang TikTok, phải có MCP.

2Cài MCP ở đâu, cài sao cho an toàn

Giống Rule và Skill ở buổi 1, MCP cũng có hai chỗ để: trong dự án hoặc cho cả máy. Khác ở chỗ: tất cả MCP của một nơi nằm chung trong một file mcp_config.json.

2.1. Project hay global

Project (dự án)Global (cả máy)

Khóa này cài project. Dễ kiểm soát: MCP chỉ chạy trong dự án video, gỡ thì sửa đúng một file trong dự án, Agent đọc và sửa giúp được. Buổi 5 mới bàn chuyện chuyển MCP dùng nhiều sang global. Để khỏi nhầm, mỗi MCP chỉ khai báo ở một nơi.
Dấu ~ là thư mục tài khoản của bạn trên máy: Windows C:\Users\TEN-BAN, macOS /Users/TEN-BAN. Thư mục .agents, .gemini bắt đầu bằng dấu chấm nên thường bị ẩn (cách hiện: xem buổi 1, phần 1).

2.2. File cấu hình trông thế nào

Mỗi MCP là một mục trong mcpServers. MCP chạy trên máy khai báo lệnh chạy; MCP trên mạng chỉ cần địa chỉ.

2.3. Bốn điều an toàn khi cài MCP lạ

MCP là phần mềm chạy thật trên máy bạn, có thể đọc file, gửi dữ liệu ra ngoài. Cài MCP lạ giống cắm một thiết bị không rõ nguồn gốc vào ổ điện, nên kiểm tra trước.

ĐiềuLàm thế nào

2. Mã khóa không dán vào khung chatCuộc trò chuyện được lưu lại, Agent có thể chép mã sang file khác. Bạn tự mở file mcp_config.json bằng Notepad (Windows) hoặc TextEdit (macOS), dán mã vào mục env, lưu.
3. Không chia sẻ file cấu hình có mã khóaKhông gửi, không chụp màn hình file đó, không đưa vào file zip dự án gửi người khác. Lỡ lộ mã: vào trang cấp mã thu hồi ngay, tạo mã mới.
4. Cho phép từng lầnGiữ Permission Preset là Request Review như buổi 1. Antigravity hỏi trước khi gọi công cụ thì đọc tên công cụ và nội dung gửi đi; công cụ có chữ delete, send, post thì dừng lại hỏi giảng viên.

Tôi gửi bạn: đường link repo MCP https://github.com/andyluu98/chatgpt-image-mcp, tôi định cài MCP này cho dự án. Việc cần làm: 1. Đọc trang README của repo. 2. 3Cài ChatGPT Image MCP

Hôm nay ta cắm Antigravity vào ChatGPT để Agent tự gửi yêu cầu vẽ ảnh và tự lưu ảnh vào dự án, bạn không phải mở ChatGPT, tải từng ảnh về.

MCP dùng trong khóa: github.com/andyluu98/chatgpt-image-mcp (repo công khai của giảng viên).

Đọc trước khi cài: theo README của repo, công cụ này đi qua giao diện web của ChatGPT chứ không qua đường chính thức của OpenAI. README ghi rõ việc dùng công cụ này vi phạm điều khoản của OpenAI, tài khoản có thể bị giới hạn hoặc khóa vĩnh viễn. Hãy dùng tài khoản ChatGPT phụ, không dùng tài khoản chính đang lưu dữ liệu quan trọng. Mã đăng nhập chỉ lưu trên máy bạn.

3.1. Cài uv

uv là trình cài Python gọn nhẹ: nó tự tải Python và các thư viện mà MCP cần, bạn không phải cài Python riêng. Làm một lần cho mỗi máy.

  1. Windows: bấm phím Windows, gõ PowerShell, mở Windows PowerShell. macOS: mở Terminal.
  2. Dán lệnh tương ứng, bấm Enter, chờ báo cài xong:
Windows: dán vào PowerShell

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS: dán vào Terminal

curl -LsSf https://astral.sh/uv/install.sh | sh

  1. Đóng cửa sổ đó, mở cửa sổ mới, gõ uv --version rồi Enter. Thấy dòng uv 0.x.x là được.

3.2. Tải repo về máy

  1. Mở trang repo ở trên, bấm nút xanh Code, chọn Download ZIP.
  2. Giải nén vào Documents. Thư mục giải nén thường tên chatgpt-image-mcp-master; đổi tên thành chatgpt-image-mcp cho dễ nhớ.
  3. Ghi lại đường dẫn thư mục: trên Windows bấm chuột phải vào thư mục, chọn Copy as path. Ví dụ C:\Users\TEN-MAY\Documents\chatgpt-image-mcp.
Không để repo trong thư mục dự án video. Repo là phần mềm dùng chung cho mọi dự án, để riêng ở Documents. Trong dự án chỉ có file cấu hình trỏ tới nó.

3.3. Chạy trình cài và đăng nhập ChatGPT

  1. Windows: mở thư mục chatgpt-image-mcp trong File Explorer, bấm vào thanh địa chỉ, gõ powershell rồi Enter. Cửa sổ PowerShell mở ra đúng tại thư mục đó.
  2. Dán lệnh dưới, Enter:
Windows: chạy trình cài

powershell -ExecutionPolicy Bypass -File install.ps1

macOS: mở Terminal tại thư mục repo rồi chạy

cd ~/Documents/chatgpt-image-mcp bash install.sh

Trình cài làm 4 bước, bạn chỉ cần trả lời các câu hỏi:

Đường link chỉ dùng được một lần, trong vài phút. Dán nhầm hay quá lâu thì chạy lại lệnh cài từ đầu. Đường link này là mã đăng nhập: không dán vào nhóm lớp, không gửi cho ai.
MCP này không cần mã khóa trong env. Mã đăng nhập ChatGPT được lưu trong file %APPDATA%\cgimg\auth.json (Windows) hoặc ~/.config/cgimg/auth.json (macOS), theo README của repo. Coi file đó như mật khẩu: không gửi, không chép vào dự án.

3.4. Khai báo MCP cho dự án

Nhờ Agent viết file cấu hình MCP của dự án (.agents/mcp_config.json). Thay đường dẫn bằng đường dẫn bạn chép ở bước 3.2.

Nhờ Agent tạo file cấu hình MCP

Tôi gửi bạn: đường dẫn thư mục MCP tạo ảnh trên máy tôi là DUONG-DAN-THU-MUC-CHATGPT-IMAGE-MCP. Việc cần làm: 1. Tạo file .agents/mcp_config.json trong dự án này với nội dung dưới đây, thay DUONG-DAN bằng đường dẫn tôi gửi (trên Windows mỗi dấu \ viết thành \\). 2. File .agents/mcp_config.json đã có thì không ghi đè: chép bản cũ vào _backup/ rồi thêm mục chatgpt-image vào trong mcpServers, giữ nguyên các mục cũ. 3. Chỉ ghi file, không chạy lệnh nào. { "mcpServers": { "chatgpt-image": { "command": "uv", "args": ["--directory", "DUONG-DAN", "run", "cgimg-mcp"], "timeoutSeconds": 300 } } } Kết quả: cho tôi xem nội dung file đã ghi.

Sau khi cài bộ buổi 3 ở phần 5, bạn có thể đối chiếu với file mẫu bo-cai/buoi-03/mau/mcp_config-mau.json.
