1Cài ChatGPT Image MCP

MCP là "ổ cắm" nối Agent sang phần mềm khác. Hôm nay ta cắm Antigravity vào ChatGPT để Agent tự gửi yêu cầu vẽ ảnh và tự lưu ảnh vào dự án, bạn không phải mở ChatGPT, tải từng ảnh về.

MCP dùng trong khóa: github.com/andyluu98/chatgpt-image-mcp (repo công khai của giảng viên).

Đọc trước khi cài: theo README của repo, công cụ này đi qua giao diện web của ChatGPT chứ không qua đường chính thức của OpenAI. README ghi rõ việc dùng công cụ này vi phạm điều khoản của OpenAI, tài khoản có thể bị giới hạn hoặc khóa vĩnh viễn. Hãy dùng tài khoản ChatGPT phụ, không dùng tài khoản chính đang lưu dữ liệu quan trọng. Mã đăng nhập chỉ lưu trên máy bạn.

1.1. Cài uv

uv là trình cài Python gọn nhẹ: nó tự tải Python và các thư viện mà MCP cần, bạn không phải cài Python riêng. Làm một lần cho mỗi máy.

  1. Windows: bấm phím Windows, gõ PowerShell, mở Windows PowerShell. macOS: mở Terminal.
  2. Dán lệnh tương ứng, bấm Enter, chờ báo cài xong:
Windows: dán vào PowerShell

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS: dán vào Terminal

curl -LsSf https://astral.sh/uv/install.sh | sh

  1. Đóng cửa sổ đó, mở cửa sổ mới, gõ uv --version rồi Enter. Thấy dòng uv 0.x.x là được.

1.2. Tải repo về máy

  1. Mở trang repo ở trên, bấm nút xanh Code, chọn Download ZIP.
  2. Giải nén vào Documents. Thư mục giải nén thường tên chatgpt-image-mcp-master; đổi tên thành chatgpt-image-mcp cho dễ nhớ.
  3. Ghi lại đường dẫn thư mục: trên Windows bấm chuột phải vào thư mục, chọn Copy as path. Ví dụ C:\Users\TEN-MAY\Documents\chatgpt-image-mcp.
Không để repo trong thư mục dự án video. Repo là phần mềm dùng chung cho mọi dự án, để riêng ở Documents.

1.3. Chạy trình cài và đăng nhập ChatGPT

  1. Windows: mở thư mục chatgpt-image-mcp trong File Explorer, bấm vào thanh địa chỉ, gõ powershell rồi Enter. Cửa sổ PowerShell mở ra đúng tại thư mục đó.
  2. Dán lệnh dưới, Enter:
Windows: chạy trình cài

powershell -ExecutionPolicy Bypass -File install.ps1

macOS: mở Terminal tại thư mục repo rồi chạy

cd ~/Documents/chatgpt-image-mcp bash install.sh

Trình cài làm 4 bước, bạn chỉ cần trả lời các câu hỏi:

Màn hình hiệnBạn làm

1.4. Thêm MCP vào Antigravity

Cách nhanh nhất: nhờ Agent viết file cấu hình MCP cho dự án (file .agents/mcp_config.json). Thay đường dẫn bằng đường dẫn bạn chép ở bước 1.2.

Nhờ Agent tạo file cấu hình MCP

Tôi gửi bạn: đường dẫn thư mục MCP tạo ảnh trên máy tôi là DUONG-DAN-THU-MUC-CHATGPT-IMAGE-MCP. Việc cần làm: 1. Tạo file .agents/mcp_config.json trong dự án này với nội dung dưới đây, thay DUONG-DAN bằng đường dẫn tôi gửi (trên Windows mỗi dấu \ viết thành \\). 2. File .agents/mcp_config.json đã có thì không ghi đè: chép bản cũ vào _backup/ rồi thêm mục chatgpt-image vào trong mcpServers, giữ nguyên các mục cũ. 3. Chỉ ghi file, không chạy lệnh nào. { "mcpServers": { "chatgpt-image": { "command": "uv", "args": ["--directory", "DUONG-DAN", "run", "cgimg-mcp"], "timeoutSeconds": 300 } } } Kết quả: cho tôi xem nội dung file đã ghi.

Cách thứ hai, qua giao diện: trong Antigravity mở Customizations, tab Installed, mục MCP Servers, bấm Add MCP Server; hoặc bấm Copy Config File Path để lấy đường dẫn file cấu hình chung rồi mở file đó, dán đoạn JSON ở trên vào.

Thêm xong, tắt Antigravity, mở lại để Antigravity nạp MCP mới.

Vị trí file cấu hình, tên mục trong giao diện và trường timeoutSeconds lấy theo tài liệu chính thức của Antigravity, tra ngày 09/11/2026. Mỗi lần gọi tool, Antigravity mặc định chờ 180 giây; ta đặt 300 giây vì tạo một ảnh có thể mất tới 90 giây. Antigravity cập nhật thường xuyên, tên mục có thể khác đôi chút trên máy bạn.

1.5. Gọi thử 1 ảnh

Tạo ảnh thử đầu tiên

Việc cần làm: 1. Gọi tool login_status của MCP chatgpt-image, báo tôi đã đăng nhập chưa. 2. Đã đăng nhập thì gọi tool generate_image một lần với: prompt "a cup of black coffee on a light wooden table, soft natural window light, neutral white balance, no text", aspect 1:1, n 1, enhance false, out_dir là đường dẫn tuyệt đối tới thư mục anh/thu trong dự án này. 3. Chưa có thư mục anh/thu thì tạo mới. Kết quả: báo tôi đường dẫn file ảnh vừa tạo.

Mở thư mục anh/thu, thấy ảnh ly cà phê là MCP đã chạy. Antigravity hỏi cho phép gọi tool thì đọc tên tool (login_status, generate_image) rồi đồng ý.
