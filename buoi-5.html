2Đăng bài có duyệt

Agent làm hết phần chuẩn bị, tới nút Đăng thì dừng. Người bấm Đăng luôn là bạn.

Agent làmViết caption, hashtag, mở TikTok Studio hoặc Meta Business Suite, chọn video, dán caption, bật nhãn AI.
Agent dừngTrước nút Đăng. Gặp trang đăng nhập hay captcha cũng dừng, báo bạn.
Bạn làmĐọc lại trang đăng trên trình duyệt, ưng thì tự bấm Đăng.Giống thư ký soạn sẵn thư, sếp đọc rồi tự bấm Gửi.

2.1. Cho Agent dùng trình duyệt (làm một lần)

Antigravity có sẵn một agent con tên browser, gọi bằng /browser, chuyên mở trang web và thao tác trên đó. Theo tài liệu chính thức, nó điều khiển chính Google Chrome đang mở trên máy bạn, nên dùng luôn các tài khoản bạn đã đăng nhập.

  1. Tạo một hồ sơ Chrome riêng cho việc đăng bài: trong Chrome bấm ảnh đại diện góc phải trên, chọn Thêm (Add) để tạo hồ sơ mới. Trong hồ sơ này đăng nhập TikTok phụ và Facebook thử. Làm vậy Agent không thấy email, ngân hàng ở hồ sơ chính của bạn.
  2. Trong hồ sơ Chrome đó, gõ vào thanh địa chỉ chrome://inspect/#remote-debugging, bật Allow remote debugging for this browser instance.
  3. Trong Antigravity mở Settings, mục Browser, phần Browser Actuation Rules: chỉ cho phép tiktok.com, facebook.com, business.facebook.com.
  4. Lần đầu Agent kết nối, Chrome hỏi cho phép: bấm Allow.
Thử kết nối trình duyệt

/browser Mở trang https://www.tiktok.com/tiktokstudio/upload rồi cho tôi biết trang đã đăng nhập chưa. Chỉ xem, không bấm nút nào, không điền gì.

Tên mục cài đặt lấy theo tài liệu chính thức của Antigravity (antigravity.google/docs), tra ngày 09/11/2026; tên mục có thể khác trên máy bạn. Tài liệu ghi trình duyệt cần máy có Node.js: Agent báo thiếu Node.js thì tải bản LTS tại nodejs.org, cài như phần mềm thường. Bản App còn có trình duyệt dựng sẵn riêng, giữ phiên đăng nhập sau khi tắt mở lại; Agent mở trình duyệt đó thì bạn đăng nhập tài khoản phụ ngay trong đó.
Bạn tự đăng nhập, không bao giờ gõ mật khẩu vào khung chat. Trang đòi đăng nhập thì Agent dừng, bạn tự gõ trên trình duyệt. Gặp captcha cũng tự làm hoặc bỏ qua, không nhờ Agent vượt.

2.2. Đăng bài đầu tiên

Đăng video lên TikTok, dừng trước nút Đăng

Dừng trước nút Đăng, chụp màn hình trang đã điền. Kết quả: bảng tóm tắt bài đăng để tôi duyệt. Tôi tự bấm Đăng.

  1. Đọc kỹ trang đăng trên Chrome: đúng video, đúng caption, nhãn AI đã bật, đúng tài khoản phụ.
  2. Ưng thì bạn tự bấm Đăng. Chép link bài đăng, dán lại cho Agent để nó ghi vào nhật ký.

Nhãn nội dung AI: TikTok và Facebook đều có mục tự khai báo nội dung tạo bằng AI khi đăng. Vị trí mục thay đổi theo bản cập nhật của từng nền tảng; Agent tìm không thấy thì bạn tự tìm, caption vẫn giữ dòng "Nội dung có sử dụng AI" theo file thương hiệu.

5Lưu lên GitHub

Bộ skill của bạn là tài sản. Lưu lên GitHub để không mất khi đổi máy, và mang sang dự án khác.

5.1. Tạo repo riêng tư (không cần dòng lệnh)

  1. Đăng nhập github.com, bấm dấu + góc phải trên, chọn New repository.
  2. Đặt tên, ví dụ bo-skill-video-TEN-BAN. Chọn Private (riêng tư). Bấm Create repository.
  3. Ở trang repo mới, bấm dòng uploading an existing file.
  4. Mở File Explorer (bật Hidden items để thấy .agents), kéo thả vào trang: thư mục .agents, file AGENTS.md, thư mục bo-cai.
  5. Kéo xuống dưới, bấm Commit changes.
Không tải lên: mật khẩu, mã khóa (API key), file .env, cookie, thư mục hồ sơ Chrome, file đăng nhập của bất kỳ công cụ nào. Không tải dữ liệu khách hàng thật. Video lớn cũng không cần đưa lên: GitHub chỉ cho tải qua trang web file tối đa 25 MB.
Nhờ Agent soát trước khi tải lên

Tìm xem có file nào chứa mật khẩu, mã khóa, cookie, số điện thoại, email, dữ liệu khách hàng thật không. 2. Liệt kê file đáng ngờ kèm dòng đáng ngờ. Kết quả: trả lời trong khung chat, không sửa, không xóa file nào.

5.2. Dùng lại ở dự án mới

Mở repo của bạn trên GitHub, bấm Code, chọn Download ZIP, giải nén. File zip của GitHub luôn bọc ngoài một thư mục tên TEN-REPO-main: mở đúng thư mục đó trong Antigravity làm dự án mới, để AGENTS.md và .agents nằm ở gốc dự án. Chạy /file-thuong-hieu cho thương hiệu mới là dùng được ngay.
