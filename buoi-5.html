2.1. Cho Agent dùng trình duyệt (làm một lần)

Antigravity có sẵn một agent con tên browser, gọi bằng /browser, chuyên mở trang web và thao tác trên đó. Theo tài liệu chính thức, nó điều khiển chính Google Chrome đang mở trên máy bạn, nên dùng luôn các tài khoản bạn đã đăng nhập.

  1. Tạo một hồ sơ Chrome riêng cho việc đăng bài: trong Chrome bấm ảnh đại diện góc phải trên, chọn Thêm (Add) để tạo hồ sơ mới. Trong hồ sơ này đăng nhập TikTok phụ và Facebook thử. Làm vậy Agent không thấy email, ngân hàng ở hồ sơ chính của bạn.
  2. Trong hồ sơ Chrome đó, gõ vào thanh địa chỉ chrome://inspect/#remote-debugging, bật Allow remote debugging for this browser instance.
  3. Trong Antigravity mở Settings, mục Browser, phần Browser Actuation Rules: chỉ cho phép tiktok.com, facebook.com, business.facebook.com.
  4. Lần đầu Agent kết nối, Chrome hỏi cho phép: bấm Allow.
Thử kết nối trình duyệt

/browser Mở trang https://www.tiktok.com/tiktokstudio/upload rồi cho tôi biết trang đã đăng nhập chưa. Chỉ xem, không bấm nút nào, không điền gì.

Tên mục cài đặt lấy theo tài liệu chính thức của Antigravity (antigravity.google/docs), tra ngày 09/11/2026; tên mục có thể khác trên máy bạn. Tài liệu ghi trình duyệt cần máy có Node.js: Agent báo thiếu Node.js thì tải bản LTS tại nodejs.org, cài như phần mềm thường. Bản App còn có trình duyệt dựng sẵn riêng, giữ phiên đăng nhập sau khi tắt mở lại; Agent mở trình duyệt đó thì bạn đăng nhập tài khoản phụ ngay trong đó.
Bạn tự đăng nhập, không bao giờ gõ mật khẩu vào khung chat. Trang đòi đăng nhập thì Agent dừng, bạn tự gõ trên trình duyệt. Gặp captcha cũng tự làm hoặc bỏ qua, không nhờ Agent vượt.

Không cho vào bộ skill: mật khẩu, mã khóa (API key), file .env, cookie, thư mục hồ sơ Chrome, file đăng nhập của bất kỳ công cụ nào, dữ liệu khách hàng thật. File zip có thể rơi vào tay người khác khi bạn cho mượn USB hay chia sẻ nhầm thư mục Drive.

5.2. Nén zip và cất, ghi phiên bản bằng ngày

  1. Mở thư mục dự án bằng File Explorer (Windows) hoặc Finder (macOS).
  2. Chuột phải vào thư mục bo-skill-cua-toi. Windows chọn Compress to ZIP file (hoặc Send to, Compressed (zipped) folder); macOS chọn Compress (Nén).
  3. Đổi tên file zip, thêm ngày hôm nay theo dạng năm-tháng-ngày: bo-skill-cua-toi_2026-11-24.zip. Ngày trong tên chính là số phiên bản.
  4. Kéo file zip lên Google Drive hoặc chép vào USB.
Lần sau sửa skill: gói lại một file zip mới mang ngày hôm đó, giữ nguyên các file cũ. Bản mới chạy kém thì mở lại file zip ngày trước là quay về được.

5.3. Cài global để dùng cho mọi dự án mới

Skill global nằm ở ~/.gemini/config/skills/TEN-SKILL/SKILL.md, agent con global ở ~/.gemini/config/agents/TEN-AGENT.md (dấu ~ là thư mục tài khoản của bạn trên máy). Thư mục này nằm ngoài dự án, mà nội quy AGENTS.md cấm Agent ghi ra ngoài dự án, nên bạn tự chép bằng File Explorer hoặc Finder.

  1. Mở thư mục global. Windows: mở File Explorer, gõ %USERPROFILE%\.gemini\config vào thanh địa chỉ, bấm Enter. macOS: mở Finder, bấm Cmd + Shift + G, gõ ~/.gemini/config, bấm Enter.
  2. Trong đó chưa có thư mục skills hoặc agents thì tạo mới (chuột phải, New, Folder; macOS chọn New Folder). Báo không tìm thấy config thì vào .gemini rồi tạo thư mục config trước.
  3. Mở cửa sổ thứ hai ở bo-skill-cua-toi trong dự án. Chép từng thư mục skill ở cột "cài global được" sang .gemini/config/skills. Chép nguyên thư mục, không chép riêng file SKILL.md.
  4. Chép từng file agent trong bo-skill-cua-toi/agents sang .gemini/config/agents.
