1Agent, Skill, MCP là gì

Hình dung bạn mở một xưởng làm video:

AgentMột nhân viên làm việc ngay trên máy bạn: tự lập kế hoạch, mở file, tạo file, làm xong báo lại.Khác chatbot: chatbot chỉ trả lời chữ, bạn phải tự chép tự làm tiếp.
SkillSổ tay quy trình viết sẵn. Gõ tên skill là Agent làm đúng các bước đó, lần nào cũng như nhau.Ví dụ: skill viết hook 3 giây (hôm nay), skill kịch bản (buổi 2).
MCPCái "ổ cắm" để Agent nối sang phần mềm khác: tạo ảnh, đọc mạng xã hội, điều khiển trình duyệt.Ví dụ: ChatGPT Image MCP ở buổi 3.

Thêm hai khái niệm sẽ gặp trong khóa:

  • Rule (quy tắc): điều Agent luôn phải nhớ, ví dụ file thương hiệu, quy tắc chống mất dữ liệu.
  • Subagent (agent con): một trợ lý chuyên một việc, Agent chính gọi khi cần, ví dụ người soát nội dung.
Thử ngay: so sánh chatbot và Agent

Tôi gửi bạn: file du-lieu/san-pham-mau.md, đây là thông tin một sản phẩm cà phê mẫu. Việc cần làm: viết 3 dòng giới thiệu sản phẩm này cho bài đăng Facebook. Kết quả: lưu vào file kich-ban/gioi-thieu-thu.md rồi báo tôi đường dẫn.

Mở file vừa tạo trong thư mục kich-ban. Đó là điểm khác chatbot: Agent tự đọc file, tự tạo file trên máy bạn.

2Cài đặt an toàn, chống mất dữ liệu

Agent làm thật trên máy bạn, nên phải đặt "phanh" trước khi giao việc lớn.

2.1. Chọn mức quyền

  1. Trong Antigravity mở Settings, mục General, phần Global Permissions, chọn Permission Preset.
  2. Chọn Default (hỏi trước các việc nhạy cảm) hoặc Request Review (lệnh nào cũng hỏi). Người mới nên chọn Request Review.
  3. Không chọn Turbo: chế độ này chạy mọi lệnh không hỏi.
Tên mục cài đặt lấy theo tài liệu chính thức của Antigravity, tra ngày 09/11/2026. Antigravity cập nhật thường xuyên, tên mục có thể khác đôi chút trên máy bạn.

2.2. Nguyên tắc chống mất dữ liệu đã có sẵn

File AGENTS.md trong dự án mẫu đã ghi sẵn: chỉ làm trong thư mục dự án, không xóa file, bản cũ chuyển vào _backup/ trước khi sửa, hỏi trước khi ghi đè, không lưu mật khẩu. Antigravity tự đọc file này mỗi lần làm việc.

Kiểm tra Agent đã nhớ quy tắc chưa

Giả sử tôi bảo bạn sửa lại file kich-ban/gioi-thieu-thu.md. Bạn sẽ làm những bước gì trước khi sửa, theo quy tắc trong AGENTS.md? Chỉ trả lời, chưa làm.

Câu trả lời đúng phải có bước chép bản cũ vào _backup/ trước khi sửa.

Ba điều không bao giờ làm: mở Antigravity ở cả ổ C:\ hay thư mục Desktop; dán mật khẩu, mã khóa vào khung chat; bấm đồng ý lệnh có chữ delete, rm, Remove-Item khi chưa hiểu nó xóa gì.

3Cách giao việc cho Agent

Bốn bước, dùng cho mọi việc trong khóa.

1. Giao rõBạn gửi gì, cần làm gì, kết quả là file gì, lưu ở đâu.
2. Đòi kế hoạchBảo Agent trình bày cách làm trước, chưa làm ngay.
3. Duyệt rồi làmĐọc kế hoạch, sửa chỗ chưa đúng, rồi mới đồng ý.
4. Kiểm traMở file Agent tạo ra, xem có đúng yêu cầu không.
Mẫu giao việc chuẩn

Tôi gửi bạn: file .agents/rules/thuong-hieu.md, đây là bộ nhận diện thương hiệu mẫu. Việc cần làm: 1. Đọc file đó. 2. Tóm tắt trong 5 gạch đầu dòng: thương hiệu bán gì, cho ai, màu chính, giọng văn, điều cấm. Trình bày kế hoạch trước, tôi đồng ý thì mới làm. Kết quả: trả lời ngay trong khung chat, không tạo file.

Mẹo: kết quả chưa ưng thì nói "Câu thứ 2 dài quá, rút còn 10 chữ" thay vì viết lại cả yêu cầu.

4GitHub cơ bản

  • GitHub là nơi lưu và chia sẻ code, tài liệu, skill. Mỗi dự án trên GitHub gọi là một repo (kho).
  • Tải repo về máy: bấm nút xanh Code, chọn Download ZIP, giải nén.
  • Rất nhiều skill hay được chia sẻ miễn phí trên GitHub. Trước khi cài skill lạ, mở file SKILL.md ra đọc xem nó làm gì, có lệnh xóa hay gửi dữ liệu ra ngoài không.
