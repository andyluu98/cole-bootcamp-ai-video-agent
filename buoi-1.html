1Mở workspace đầu tiên

Workspace là một thư mục trên máy mà bạn giao cho Agent làm việc. Agent chỉ đọc, ghi trong thư mục đó. Mỗi dự án video là một workspace riêng.

Chưa cài Antigravity thì làm trang Chuẩn bị trước.

  1. Tải du-an-mau.zip, giải nén vào thư mục Documents. Bạn sẽ có thư mục du-an-video. Windows có thể tạo thêm một lớp du-an-mau bên ngoài: mở đúng thư mục du-an-video, là thư mục có file AGENTS.md.
  2. Mở Antigravity App, mở thư mục du-an-video làm workspace (nút Open Folder hoặc thêm thư mục vào project, tùy phiên bản).
  3. Mở một cuộc trò chuyện mới, dán câu lệnh:
Dán vào Antigravity

Chào bạn. Tôi vừa mở thư mục này cho bạn làm việc. Bạn đọc file AGENTS.md rồi cho tôi biết: 1. Thư mục này có những thư mục con nào, mỗi cái để làm gì. 2. Những quy tắc nào bạn phải tuân theo khi làm việc ở đây. Trả lời ngắn gọn, không tạo hay sửa file nào.

4.2. Thực hành: tạo một rule global

Rule global là thói quen của bạn, đi theo mọi dự án. Bạn tự tạo bằng giao diện, không nhờ Agent, vì nội quy dự án cấm Agent ghi ra ngoài workspace.

Nội dung rule global (dán vào ô rule)

Bạn đang theo những quy tắc nào? Chia làm 2 nhóm: quy tắc global (dùng cho mọi dự án) và quy tắc của workspace này. Mỗi quy tắc ghi nó nằm ở file nào. Chỉ trả lời, không sửa gì.

5.1. Nội quy chống mất dữ liệu có sẵn trong AGENTS.md

  1. Chỉ đọc, ghi file trong thư mục dự án.
  2. Không bao giờ xóa file. File bỏ đi chuyển vào _backup/.
  3. Trước khi sửa file đã có: chép bản cũ vào _backup/ kèm ngày giờ.
  4. Không ghi đè file trùng tên, phải hỏi trước.
  5. Lệnh có thể xóa, ghi đè, cài phần mềm: nói rõ và chờ bạn đồng ý.
  6. Không lưu mật khẩu, mã khóa vào file hay khung chat.

5.2. Thử giao một việc trái nội quy

  1. Dán câu lệnh có /plan ở đầu: Agent chỉ trình kế hoạch, chưa làm.
