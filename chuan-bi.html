Làm trước buổi 1

Chuẩn bị máy và tài khoản

Khoảng 20 phút. Làm xong 4 bước dưới đây, buổi 1 bạn chỉ việc mở máy và học. Vướng ở đâu, chụp màn hình gửi vào nhóm lớp.

Hạn: trước 20:00 thứ 3, 10/11/2026

1Máy tính

  • Windows 10/11 hoặc macOS.
  • RAM từ 8GB, ổ đĩa còn trống tối thiểu 30GB (buổi 4 dựng video cần nhiều chỗ).
  • Máy công ty bị khóa cài phần mềm thì dùng laptop cá nhân.

3Cài Google Antigravity

  1. Vào antigravity.google/download, tải bản Antigravity App đúng hệ điều hành (Windows hoặc macOS).
  2. Mở file vừa tải, cài như phần mềm bình thường.
  3. Mở Antigravity, đăng nhập bằng tài khoản Google.
  4. Vào Settings, mục General, phần Global Permissions, đặt Permission Preset là Request Review (lệnh nào cũng hỏi bạn trước). Không chọn Turbo.
Tên mục cài đặt lấy theo tài liệu chính thức của Antigravity (antigravity.google/docs), tra ngày 09/11/2026. Phần mềm cập nhật thường xuyên nên vị trí mục có thể khác đôi chút.

4Tải thư mục dự án và thử Agent

  1. Tải du-an-mau.zip, giải nén vào thư mục Documents (hoặc chỗ nào bạn dễ tìm). Bạn sẽ có thư mục du-an-video.
  2. Trong Antigravity chọn Open Folder, chọn thư mục du-an-video.
  3. Dán câu lệnh sau vào khung chat:
Dán vào Antigravity

Chào bạn. Bạn đọc file AGENTS.md trong thư mục này và cho tôi biết 3 quy tắc quan trọng nhất bạn phải tuân theo. Trả lời ngắn, không tạo hay sửa file nào.

Agent trả lời đúng các quy tắc (không xóa file, sao lưu vào _backup/, hỏi trước khi làm việc nhạy cảm) là máy bạn đã sẵn sàng.

  • Mở được Antigravity, đã đăng nhập Google.
  • Đã đặt Permission Preset là Request Review.
  • Mở được thư mục du-an-video, Agent trả lời câu lệnh thử.
  • Đã có tài khoản GitHub.
