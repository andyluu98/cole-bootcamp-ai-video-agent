Trạm 1 · Cho Agent dùng trình duyệt

Thiết lập một lần, dùng cho mọi bài đăng

Antigravity có sẵn agent con /browser, điều khiển chính Google Chrome trên máy bạn.
01
Hồ sơ Chrome riêng

Tạo hồ sơ mới, chỉ đăng nhập tài khoản TikTok phụ và Trang Facebook thử. Bạn tự đăng nhập một lần.

02
Bật kết nối

Mở chrome://inspect/#remote-debugging, bật cho phép. Lần đầu Agent kết nối, bấm Allow.

03
Giới hạn trang

Settings, Browser, Browser Actuation Rules: chỉ cho phép tiktok.com, facebook.com.

Nguồn: antigravity.google/docs, mục Subagents và Chrome profile, tra ngày 09/11/2026. Tên mục có thể khác theo phiên bản.

Trạm 4 · Lưu lên GitHub

Repo riêng tư, kéo thả, không cần dòng lệnh

1github.com, dấu +, New repository
2Đặt tên, chọn Private, Create repository
3Bấm "uploading an existing file"
4Kéo thả .agents, AGENTS.md, bo-cai
5Commit changes
Không tải lên
  • Mật khẩu, mã khóa (API key), file .env
  • Cookie, thư mục hồ sơ Chrome, file đăng nhập
  • Dữ liệu khách hàng thật
Nhờ Agent quét file nhạy cảm trước khi tải lên. Dùng lại: Code, Download ZIP, giải nén vào dự án mới.

Trạm 5 · Đặt lịch chạy

Hẹn giờ phần chuẩn bị, giữ quyền duyệt

/schedule trong khung chat

Hẹn một lần hoặc lặp lại.

Lịch thuộc về cuộc trò chuyện đã tạo ra nó.

Automations trong App

Việc định kỳ, vẫn chạy khi đã đóng cuộc trò chuyện.

Mỗi lần chạy mở một cuộc trò chuyện mới.

Chạy theo lịch: quy trình chỉ làm tới Điểm duyệt 1 rồi dừng, ghi nhật ký, chờ bạn vào duyệt. Không bao giờ tự đăng.
