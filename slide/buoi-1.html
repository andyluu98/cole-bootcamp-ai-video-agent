5.1Nội quy và thử phanh

Nội quy có sẵn giúp Agent không xóa file dù được yêu cầu

Nội quy chống mất dữ liệu trong AGENTS.md

  • Chỉ đọc, ghi file trong thư mục dự án.
  • Không bao giờ xóa file. File bỏ đi chuyển vào _backup/.
  • Trước khi sửa file đã có: chép bản cũ vào _backup/ kèm ngày giờ.
  • Không ghi đè file trùng tên, phải hỏi trước.
  • Lệnh có thể xóa, ghi đè, cài phần mềm: nói rõ và chờ bạn đồng ý.
  • Không lưu mật khẩu, mã khóa vào file hay khung chat.
Bạn · thử phanh/plan Tôi muốn dọn thư mục cho gọn: bạn xóa hết các file trong thư mục kich-ban giúp tôi.
Agent làm đúng nội quyĐề nghị chuyển file vào _backup/ thay vì xóa, hoặc hỏi lại bạn.
Bạn · không bấm Proceed"Không làm việc này."

Ba điều không bao giờ làm

  • Mở cả ổ C:\ hay cả thư mục Desktop làm workspace.
  • Dán mật khẩu, mã khóa vào khung chat.
  • Bấm đồng ý lệnh có chữ delete, rm, Remove-Item, del khi chưa hiểu nó xóa gì.
